3. 登录后进入工作台，可使用系统消息、系统助手、常用功能和窗口管理。

### 2. 物料请购需求分析

#### 页面字段/条件

| 字段或动作 | 用途 |
| --- | --- |
| 客户订单 | 选择待分析的客户订单 |
| 查询 | 按客户订单拉取 MRP 需求 |
| 汇总方式 | 需支持“不汇总” |
| 请购数量原则 | 选择“按 MRP 需求数量请购” |
| 只显示物料请购数量大于 0 | 仅显示必须请购的项目 |
| 客户订单明细 | 勾选/选择要生成请购单的明细 |
| 生成请购单 | 生成采购侧后续使用的请购单 |
| 请购单号 | 审核完成后提供给采购员 |
| 审核状态 | 跟踪请购单处理进度 |

#### 操作步骤

1. 进入“物料需求模块 → 物料请购需求分析”。
2. 选择客户订单并查询。
3. 设置 MRP 分析原则。
4. 选择需要请购的订单明细，生成请购单。
5. 核对物料编码、单位、数量。
6. 发部门负责人审核，审核后将请购单号交采购人员。

#### 注释与规则（必须实现）

- `汇总方式：不汇总`：目的是保证采购端单据异常时能够追溯到来源需求。
- `按 MRP 需求数量请购`：请购数必须考虑 MRP 需求、在途量和库存可用量。
- `只显示请购数量 > 0`：该筛选结果才是实际必须采购的项目。
- 审核前的核对项至少包括：物料编码、单位、数量。

#### 页面字段与动作

| 字段/动作 | 说明 |
| --- | --- |
| 凭单日期 | 选择要生成凭单的日期 |
| 供应商 | 选择交易对象 |
| 保存 | 保存单头信息 |
| 工具 → 自动生成应付凭单明细 | 根据条件生成明细 |
| 查询 | 查询可生成凭单的行 |
| 选中行 | 选择需处理的来源行 |

#### 注释与规则（必须实现）

- 供应商存在送货或退货时，可以自动生成应付凭单。

### 4. 采购退货单

#### 页面字段与动作

| 字段/动作 | 说明 |
| --- | --- |
| 供应商代码 | 放大镜查询并选择供应商 |
| 是否补货 | 默认勾选；可取消 |
| 保存 | 保存后系统自动生成退货单号 |
| 采购单号 | 按 Tab 到明细行后查询并选择 |
| 退货数量 | 选择采购单后系统自动带出，需确认 |
| 退货原因 | 需要确认/填写 |

#### 流程

1. 采购模块进入退货单并新增。
2. 选择供应商。
3. 确认是否补货，保存生成退货单号。

- 采购退货审核成功应有明确视觉状态“审”，并记录审核人、审核时间。

### 5. 非生产采购

#### 适用范围

- 固定资产。
- 维修工具类。
- 其他内部需要报价及采购流程、但不应增加系统库存的物料。

#### 需要填写/选择

| 字段 | 说明 |
| --- | --- |
| 物料类型 | 必须能识别“非生产物料” |
| CC | 培训材料特别强调，建议定义为成本中心并由业务确认含义 |
| 采购业务信息 | 按常规报价、采购流程维护 |
| 收货方式 | 必须选择“非生产收货” |

#### 注释与规则（必须实现）

- 非生产采购不增加系统库存数量。

- 非生产采购单必须走“非生产收货”；正常采购收货必须禁止并提示原因。

## 四、建议固化为系统规则的清单

### 审核与可追溯性

1. 请购、采购、送货、退货、应付均需状态流转：草稿、待审核、已审核、驳回/作废（后两项需业务确认）。
2. 所有审核动作记录审核人、审核时间、审核意见。
3. 请购单明细、采购单明细、退货补货单、应付凭单来源行之间必须保留来源单号和来源明细 ID。
4. 请购 MRP 分析应保留计算快照：需求量、在途量、可用库存、最终请购量及分析规则。

### 强制校验

1. 送货：SRM 与 ERP 的客户 PO、物料编码、名称、数量一致性校验。
2. 销售退货：原出货库位为 FG01 时，默认/强制退入不良品仓。
3. 采购：审核前检查币种、部门、支付方式、税率、采购数量、单价。
4. 应付：按支付方式拆凭单；收货来源需同时勾选表头和明细。
5. 采购退货：勾选补货时自动生成补货采购单；取消时禁止生成。
6. 非生产采购：阻止使用正常采购收货；不写入库存余额。

## 五、待业务确认项

| 问题 | 原因 |
| --- | --- |
| `CC` 的正式中文名称与编码规则 | 材料只写“cc”，通常可能表示成本中心，但需确认 |
| 请购单转采购单的菜单归属 | 材料写“销售模块中的请购单转采购单”，但业务上通常归采购/物料需求模块 |
| “供应商代送”时的库存、成本和应收确认时点 | 培训材料说明供应商直接送货，但未定义财务与库存处理规则 |
| 客户 PO 与 SRM 单号的关系 | 材料要求录入/核对，未说明一对多及变更策略 |
| 不良品仓编码与返修后的质检放行规则 | 仅举例 FG01，未给出不良品仓实际编码和质量判定流程 |
| 应付凭单生成口径 | 需明确按收货、按退货、按发票、按税率、按币种是否都需要拆分 |
