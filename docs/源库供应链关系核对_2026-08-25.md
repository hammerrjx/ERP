# coerp_dgyzx1 供应链关系核对

核对时间：2026-08-25。数据源仅以 `.env` 指定的 SQL Server 连接只读查询，未执行写入。

## 已确认的关系

| 本地业务对象 | 源库视图与关联键 | 本地实现 |
| --- | --- | --- |
| 销售订单行到请购行 | `v_req_sod_qty`：`req_pr_nbr`、`req_line`、`sod_part`、`sod_req` | `PurchaseRequisitionLine.source_sales_order_line` 保留来源销售订单行；不汇总 MRP 请购要求此来源。 |
| 请购行到采购订单行 | `v_pod_req_so`：`pod_nbr`、`pod_line` 对应 `req_pr_nbr`、`req_line` | `PurchaseOrderLine.source_requisition_line` 保留请购行来源。 |
| 采购收货 | `v_prh_receiver` 为收货单头；`v_prh_hist` 以 `prh_receiver`、`prh_nbr`、`prh_line` 关联采购单与行 | `GoodsReceipt.purchase_order`、`GoodsReceiptLine.purchase_order_line` 保留关系；源对象标识校正为 `prh_receiver`、`prh_hist`。 |
| 出货 | `v_sdh_so_po` 和出货历史以 `sdh_so_nbr`、`sdh_sod_line` 关联销售订单行 | `DeliveryOrder.sales_order`、`DeliveryOrderLine.sales_order_line` 保留关系。 |
| 库存交易 | `v_tr_hist` / `v_tr_ref_line` 通过 `tr_part`、`tr_loc`、`tr_lotserial`、`tr_ref`、`tr_ref_line` 追溯 | 本地库存余额与流水按物料、库位、批次和来源行记录。 |
| 应付 | `v_ap_grnd` / `v_apd_line` 以收货单、采购单、行号和来源单号形成应付来源 | `PayableVoucherLine.source_receipt_line` 或退货行一对一关联，并继承采购行单价、币种、支付方式和税率。 |
