## 1. 业务范围

PPT 覆盖三类操作：

1. 物料信息建立
2. 供应商资料建立
3. 供应商报价

共同生命周期：新增/保存 -> 部门或业务审核 -> 审核通过后可被后续业务单据使用。系统应保存审核人、审核时间、录入人、录入时间和修改痕迹。

## 2. 物料信息

### 2.1 建立流程

1. 进入“基础资料 -> 物料信息”。
2. 点击“新增”。
3. 填写基本属性、工程属性、库存属性、MRP 属性。
4. 选择适用的主体公司，可多选；未勾选的主体不能使用该物料做业务数据。
5. 保存后由部门负责人/指定审核人审核。
6. 审核通过后物料正式生效。

### 2.2 基本属性字段

| 字段 | 规则/用途 |
| --- | --- |
| 物料编码 | 系统自动生成；产品类确定后生成对应编码，允许配置编码规则 |
| 物料名称 | 必填；与规格共同用于区分实物 |
| 英文名称 | 可选 |
| 海关物料编码 | 可选 |
| 海关物料名称 | 可选 |
| 产品类 | 必填；从产品类主数据选择，不建议自由输入 |
| 物料单位 | 必填；必须使用规范中文单位，不允许 `KG/G/PCS/PC` 等英文单位 |
| 旧物料编码 | 可选，用于历史编码映射 |
| 条码 | 可选 |
| 税务编码 | 必填；需与供应商核对，由工程师维护 |
| 税务名称 | 与税务编码关联 |
| 开票名称 | 可选/用于发票 |
| 适用主体公司 | 必填；多选关系，决定公司范围内是否可用 |
| 审核人、审核日期 | 系统回写，确保可追溯 |
| 相关图片/附件 | 通过附件管理关联，不把图片路径硬编码在业务表 |

#### 单位及转换率

物料要保存库存基本单位，以及不同业务环节的换算关系。PPT 特别强调销售单位和库存单位换算错误会导致需求运算、出入库数量错误。

- 工程 BOM：每 `工程数量` `工程单位` = `库存数量` `库存单位`
- 生产领用：每 `领用数量` `领用单位` = `库存数量` `库存单位`
- 采购：每 `采购数量` `采购单位` = `库存数量` `库存单位`
- 销售：每 `销售数量` `销售单位` = `库存数量` `库存单位`

建议建独立的 `material_uom_conversion` 明细，而不是为四个环节复制一组不可校验的字符串字段。换算率必须大于 0，单位必须引用计量单位主数据，保存时校验方向和精度。

默认库位为 PPT 标注的必填项；物料与库位是外键关系，不能仅保存库位名称。

## 3. 供应商资料

### 3.1 建立流程

1. 进入“采购模块 -> 供应商资料”。
2. 点击“新增”。
3. 填写供应商识别信息、联系方式、支付/税务/财务信息。
4. 选择供应商适用的主体公司，可多选。
5. 保存并审核；审核通过后才能在报价和采购订单中使用。

### 3.2 基本信息字段

| 字段 | 规则/用途 |
| --- | --- |
| 供应商代码 | 必填；可系统自动生成或按编码规则生成 |
| 简称 | 必填 |
| 全称 | 必填 |
| 地址 | 联系地址 |
| 网址 | 可选 |
| 采购员 | 责任采购员 |
| 常用币种 | 引用货币主数据 |
| 支付方式 | 必填；必须选择带“供应商”语义的支付方式；支持多个对账/付款方式 |
| 报价方式 | 如含税价/未税价 |
| 增值税率 | 税率；发票类型影响默认税率，普通发票示例为 0，增值税专用发票示例为 13 |
| 发票类型 | 如增值税专用发票 |
| 类型 | 至少区分“材料采购供应商”和“外协加工供应商” |
| 供应商单价取值 | 如最高报价等取价策略 |
| 供应商单价系数 | 默认报价系数 |
| 备案比例 | 业务比例 |
| 超收货比例 | 收货容差 |
| 法人 | 企业法人 |
| 注册资金（万元） | 企业资料 |
| 营业额（万元） | 企业资料 |
| 税号 | 税务识别号 |
| 员工人数 | 企业资料 |
| 开业日期 | 日期 |
| 服务评分 | 供应商评价 |
| 备用支付方式 2/3 | 多支付方式 |
| 是否内部公司 | 内部往来标识 |
| 入库库位 | 默认入库库位，引用库位主数据 |
| 应付/暂估/委托加工财务科目 | 财务科目引用，具体字段按会计科目表配置 |
| 备注 | 可选 |
| 开户行、银行账号、银行行号、其他信息 | 银行账户明细，允许一对多 |
| 适用主体公司 | 多选关系，决定哪些公司可使用该供应商 |
| 录入/审核人及时间 | 审计字段 |

供应商联系人应为独立一对多明细，至少支持：联系人、职位、联系电话、传真、电子邮箱。不要限制为单个联系人字段。

## 4. 供应商报价

### 4.1 操作流程

1. 进入“采购模块 -> 供应商报价”。
2. 点击“新增”。
3. 选择供应商代码（放大镜/查询选择）。
4. 选择物料编码（放大镜/查询选择）。
5. 填写币种、含税标记、增值税率、生效日期、失效日期、报价类型、单价和最小数量。
6. 保存并审核；审核通过后影响后续采购订单价格。
7. 批量报价时按 Tab 进入明细行，录入数量阶梯和单价。

### 4.2 报价字段

| 字段 | 规则/用途 |
| --- | --- |
| 报价单号 | 系统自动编号 |
| 供应商代码 | 必填；引用已审核供应商 |
| 物料编码 | 必填；引用物料 |
| 币种 | 引用货币 |
| 生效日期 | 必填；决定何时可取价 |
| 失效日期 | 必填/建议必填；会影响后续采购订单取价 |
| 报价类型 | `P.采购报价` 或 `S.外协报价` |
| 含税 | 是否含税 |
| 增值税率 | 含税报价需要核查税率 |
| 材料单价 | 采购报价使用；不应与加工单价混用 |
| 加工单价 | 外协报价使用 |
| 最小采购数量 | 可选；PPT 说明可小于物料 MRP 中的最小采购量 |
| 最小包装数量 | 可选 |
| 备注 | 可选 |
| 数量阶梯 | 明细行的“数量大于等于”条件 |
| 阶梯材料单价 | 采购报价明细单价 |
| 阶梯加工单价 | 外协报价明细单价 |
| 审核人、审核时间 | 审核审计 |

业务区别：材料采购供应商只提供原材料；外协加工供应商既提供原材料，也提供外协加工服务。因此报价类型决定价格字段和后续采购/外协单据的取价逻辑。

### 4.3 价格有效性约束

- 同一供应商 + 同一物料 + 同一报价类型 + 同一币种的有效日期区间不得重叠。
- 失效报价不能带入新采购订单。
- 未审核报价不能参与正式取价。
- 含税报价必须校验税率；未税报价不应错误套用含税税率。
- 阶梯报价按数量从小到大匹配，且数量条件不能重复或出现无法覆盖的歧义。

## 5. 主数据关系

建议首期至少建立以下关系：

```text
ProductCategory 1 --- n Material n --- 1 Uom
Location         1 --- n Material (default_location)
Currency         1 --- n Supplier
Supplier         n --- n Company
Material         n --- n Company
Supplier         n --- n Material (SupplierQuote)
SupplierQuote    1 --- n SupplierQuoteLine
Material         1 --- n MaterialUomConversion
Supplier         1 --- n SupplierContact
Supplier         1 --- n SupplierBankAccount
```

必须使用外键/中间表保存这些关系，不能只存截图中的显示名称。特别是产品类、库位、货币、计量单位、物料、供应商之间的关联，会直接影响后续采购价格、库存位置、MRP 和财务取值。

## 6. 首期实现验收清单

- [ ] 产品类、库位、货币、计量单位可先于物料和供应商建立。
- [ ] 物料表单分为基本、工程、库存、MRP 四个页签。
- [ ] 物料编码按产品类和编码规则自动生成，并支持历史编码。
- [ ] 中文单位校验，拒绝 `KG/G/PCS/PC` 等英文单位。
- [ ] 物料税务编码、产品类、单位、默认库位为必填或按业务配置必填。
- [ ] 物料可多选适用主体公司，未关联公司不能使用。
- [ ] 使用中、无库存进出记录、非生产物料、计划订单等开关可落库并影响业务校验。
- [ ] 四类业务单位换算可配置、可校验、可追溯。
- [ ] 供应商支持多联系人、多银行账户、多支付方式及多主体公司。
- [ ] 供应商类型区分材料采购与外协加工。
- [ ] 供应商审核前不可用于报价/采购。
- [ ] 报价区分采购报价和外协报价，分别维护材料单价和加工单价。
- [ ] 报价支持生效/失效日期、税率、币种、最小采购量、数量阶梯。
- [ ] 报价审核和有效期参与采购订单取价。
- [ ] 所有主数据保留录入、修改、审核人及时间。
